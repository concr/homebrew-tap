# homebrew-tap

```bash
# list my tap
brew tap-info concr/tap
```

## Casks

### airport-konfigurator

Configure and manage AirPort base stations without AirPort Utility.

```bash
# show remote recipe 
brew cat --cask concr/tap/airport-konfigurator

# lint remote recipe
brew audit --cask --strict concr/tap/airport-konfigurator

# check upstream for new version
brew livecheck --cask concr/tap/airport-konfigurator
```
